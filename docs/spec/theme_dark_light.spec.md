# 深色/浅色主题支持的规格说明

以当前主题系统为基础：[规格说明](theme_spec.md)

为系统添加 `深色`/`浅色`主题的支持。

## 设置入口

+ admin管理界面，主题设置，额外添加一个模块，可以选择 `自动`/`浅色`/`深色`，作用范围：全站默认设置。
+ 大厅页面，顶栏主题设置，添加模块，可以选择 `自动`/`浅色`/`深色`，作用范围：当前用户设置，覆盖全站默认
+ 房间设置，主题设置，添加模块，可以选择 `自动`/`浅色`/`深色`，作用范围：房间，覆盖所有参与者的设置（仅在本房间生效）

## `自动`/`浅色`/`深色` 行为表述

+ `自动`：按照用户系统设置来自动切换深色/浅色主题。如果用户系统/浏览器不支持，则默认浅色。
+ `浅色`：使用主题的浅色版本
+ `深色`：使用主题的深色版本


## 现有主题的改造

重新目前已有的主题，分为`深色`和`浅色`两个版本，应当遵循主题本色设计理念。

已有主题可参考[规格说明](theme_spec.md)中的**主题列表**
