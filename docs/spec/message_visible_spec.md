# 消息可见性规格说明

## 基本描述

在房间中，总共会有以下2类频道

- 默认的公共频道，包括所有参与者和bot
- 私聊频道，hoster和player的一对一频道

同时除了来自hoster和player（包括bot的）之外，还会有系统消息。

系统消息包含以下几类

- 投掷信息（明骰和暗骰），可以参考`command_spec.md`中的投掷类型指令，包括由kp发起的检定需求（参考`require_check_spec.md`）
- 使用指令对自己设置属性，可以参考`command_spec.md`中的st指令
- hoster发送道具（线索/人物/信息/物品）的提示
- 其他系统提示：如.help指令


## 可见度描述

### 来自参与方的消息

遵循：在什么频道发的，就出现在什么频道，频道里的人就可以看见。
举例来说，公共频道消息，就公共频道里的所有人都可以看见这条消息。而私聊1v1频道，因为频道里只有2个人，那么就只有你和对方可以看见。

### 系统通知

系统通知依然遵照：在什么频道里发生，则发送到什么频道的原则，只是有些信息未必会对频道所有人可见

#### 投掷信息

无论是自己使用.rd/.rc/.ra/.sc指令还是使用ui的投掷功能，此类信息都在当前频道发送并对所有人可见。
由kp发起的`普通检定`和`理智检定`也遵循一样的原则。

**特殊情况：暗骰/.rh指令**

该消息同样会出现在当前频道内，但是其他人不可见，仅对自己可见。

**特殊情况：kp发起的心理学暗骰**

该情况与暗骰类似，投掷结果仅对kp自己可见，player仅能收到kp对你发起了暗骰的信息，不会展示任何结果。

#### 设置信息（.st指令）

`.st` 指令的信息仅对使用者自己可见

#### 道具发送（host操作）

发送信息仅对host和被发送目标可见，未在范围内的参与者看不到此类信息。
