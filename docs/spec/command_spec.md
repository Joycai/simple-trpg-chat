# 房间指令规格说明

## 描述

参与者可以在房间内使用`.command`格式的输入，执行各种指令。

- 参与者：包括玩家`Player`和房间主持人`Hoster`

## 指令格式

- 指令一标准格式`.{command} {args}`，但是兼容描述的变体：`.`或者`。`开头均可接受，`{command}`与参数间空格可选
- 指令如无特别说明，为`Player`和`Hoster`均可使用。
- 指令**可见度**除非有特殊说明，默认遵循以下可见规则：
   - 在`公频消息`中使用的指令，对所有人可见
   - 在`私聊`频道里，使用指令的反馈针对私聊双方可见（不会在`公频消息`广播）
   - 如果指令无效，无论是格式错误或者参数缺失，禁止静默失败，需要展示错误提示，并给出可能的猜测。
   - 指令反馈：需要包含`原始指令`+`反馈信息`： 举例说明，“玩家1使用了.{command} {args}” 换行， "{执行结果文本}"

## 指令列表

指令均以`.{command} {args}`给出，但是要求兼容变体格式

### 帮助 

指令：`.help`

说明：展示出当前可用的指令

可见度说明：仅对使用了该指令的参与者可见，当前频道其他人不可见。

示例反馈

```markdown
.rd 投点指令，如.rd100, .rd20
.rhd 暗投指令
...
```


### 投掷点数

指令举例：

- `.rd` 等价于`.rd100`, 代表投掷一个d100检定
- `.r2d100` 多个同面值投掷，代表投掷2个d100检定
- `.r2d100+5d10+3d6` 不同面数的串联投掷，代表投掷2个d100检定+5个d10检定+3个d6检定。可以无限制串联。
- `.r2d100k1+5d10k2+3d6` 不同面数的串联投掷，并针对其中部分骰子取最大数量。代表投掷2个d100检定（取最大的一个）+5个d10检定（去最大的两个）+3个d6检定。可以无限制串联。

**变体指令**

指令变体从`.r`变为`.rh`，支持完全一致的feature。仅修改**可见度**为隐蔽投掷，仅使用者自己可见。（举例：私聊频道中，仅使用者自己看到投掷结果。公频消息中，也仅自己看到投掷结果。）

举例：
- `.rh` 等同于`.rhd` 和 `.rhd100` 为投掷d100，**且结果仅对自己展示**。
- `.rh2d100k1+3d10k2+1` 则投掷2个d100取1个最大+3个d10取最大的2个+1， **结果仅对自己展示**。

### 技能检定

指令：`.rc {技能/属性名}{技能点数}`或者`.ra {技能/属性名}{技能点数}`。 `{技能点数}`为可选项. `.rc`与`.ra`仅为指令变体，无区别
举例： `.rc 侦查`;`.rc 聆听60`

指令说明：
该指令需要参与者设置了自己角色卡的`技能`或`属性`. 当`技能`与`属性`存在同名时，优先使用`技能`
举例
- 如输入`.rc 体质`。首先检查该参与者角色卡是否用名为`体质`的技能，如果有，则使用该技能值进行d100的检定。如果没有，则检查是否有名为`体质`的属性，如有，则使用该属性值进行检定。如果均无，则提示用户使用`.st`设置。
- 如输入`.rc 侦查90`。则以“侦查=90”进行技能检定。忽略参与者自己的同名`技能`或`属性`的值。

### 设置技能

指令：`.st {技能}{技能点数}`
指令说明： 把玩家的`技能`设置为`{技能点数}`所示数值。技能可以串联

举例：
- `.rc 聆听90` 把玩家名为`聆听`的`技能`设置为`90`点
- `.rc 聆听90跳跃20` 把玩家名为`聆听`的`技能`设置为`90`点；把玩家名为`跳跃`的`技能`设置为`20`点

可见度：本指令仅自己可见

#### 规则适配

当hoster在**房间设置**里设置了某种**规则模版**时，有额外附加逻辑。

**规则模版：COC 7th**

**专属属性设置**
以下`技能名`需要作为`属性`设置，而非`技能`。
- `力量`(str)
- `体质`(con)
- `体型`(siz)
- `敏捷`(dex)
- `外貌`或者`魅力`(app)
- `智力`(int)
- `意志`(pow)
- `教育`(edu)
- `幸运`(luk)

注意这些名字存在等价关系。举例：`.st 外貌50` 与 `.st 魅力50` 与 `.st app50` 均代表将的`外貌`属性设置为`50`。

**专属资源设置**
以下`技能名`需要作为`资源`设置，而非`技能`。
- `生命值`(hp)
- `魔法值`(mp)
- `理智值`(san)
注意，针对此列表中的`资源`设置，仅对`当前值`设置，不影响`最大值`

### SanCheck

注意，本指令仅在房间规则模版为**COC 7th**时可用，否则提示失败。

指令格式：`.sc {成功减值表达式}/{失败减值表达式}`

指令说明：
- 先检测使用者是否设置了`理智值`资源，如果没有设置，则提示并给出.st指令使用说明
- 使用`理智值`资源的当前值进行d100检定，通过则使用`{成功减值表达式}`计算出`理智值`减值；未通过则使用`{失败减值表达式}`计算出`理智值`减值
- 将**减值**更新到`理智值`资源的当前值

举例说明：
当前使用者`理智值`资源为60. 输入`.sc 0/1d6`。则进行目标为60的d100检定。
如果出目高于60，则检定失败，再投掷1d6，假设出目2，则更新`理智值`资源为58.
如果出目低于60，则检定失败，则更新`理智值`资源为60-0=60. 不变。
