# hoster发起检定的功能需求

hoster可以主动要求房间内的成员进行检定（包括bot）。操作方式是点击顶部工具栏的“发起检定”按钮，然后选择需要检定的人员，再选择需要检定的`技能`。然后点击“发起”。

- 检定的范围为当前房间-》当前频道内的成员。也就是在公共频道内，可以选择全部的人员，私聊情况下，默认直接对私聊对象发起。
- 可以选择“要求全员（不含bot）”来选择除bot和自己外的所有人进行
- 可以单独选中房间内的成员，然后点击发起检定，来对需要检定的玩家发起检定。这个成员列表中，需要区分bot和player
- 检定信息会在当前频道发出，且频道成员均可见。
  - host会看到这样的信息：自己发起某个技能要求检定
  - 其他成员（被指定的）会看到：hoster要求你进行`技能`检定，并附带一个投掷的视觉图标；点击该图标可以直接进行检定；如果该成员没有设置这个技能，会弹出框要求其先设定该技能数值，数值会被直接保存到该成员的技能里。然后再自动完成检定。
    - 指定者完成本次检定请求后，不能再次投掷（投掷图标失效/不可再点击）。
  - 其他成员（未被指定的）会看到：host 要求【目标列表】来进行技能检定，但是不会有投掷图标
- 当目标投掷后，host自己会看到消息，x/y人已经完成检定。
- 如果要求bot检定，bot也可以响应【如果勾选了tool】

投掷规则参考 [指令](command_spec.md) 中有关`ra/rc`指令的描述。设置技能的逻辑参考`.st`部分。


## 规则限定特殊检定

当房间规则模版设置为特殊值时，会出现某些规则的特定检定按钮。

### 规则模版： Coc7th

当房间规则模版设置为coc7th时，在工具栏host功能区域，额外添加如下功能

#### 心理学暗投

按钮名：**心理学暗骰**

描述：

在coc7th规则下，`心理学`技能由kp进行暗骰（暗骰解释可以参考[投点规则](command_spec.md)中的`.rh` 指令）。
该按钮作用与**发起检定**类似，但不需要pl端进行操作。pl仅会收到通知（如“kp为你进行了心理学检定”）但不反馈结果。
kp可以选中若干player，然后发起**心理学暗骰**。系统会读取player的技能设置中的“心理学”技能，然后进行检定，并**仅对kp**展示结果。
补充情况：如果玩家没有设置“心理学技能”，则进行一个普通的d100检定（但是给kp展示的消息依然表明这是心理学暗骰）。

#### sancheck （理智检定）

按钮名：**理智检定**

描述：

在coc7th规则下，有特殊理智检定。该检定逻辑参考[投点规则](command_spec.md)中的`.sc` 指令。

kp发起该检定后，首先输入`成功减损值`和`失败减损值`，减损值可以是>=的整数，或者是骰子表达式（可参考`.sc`指令）。然后选择需要检定的player（与“发起检定”一致）。

剩余流程与“发起检定”完全一致：player会收到通知，并可以点击骰子进行投掷。与“发起检定”的区别是，该检定使用的是player的资源“理智值”的当前值进行检定，并且会根据结果进行扣减。（逻辑参考`.sc`指令）

请注意，如果一次性损失超过5点，会额外提示（因为coc7th规则下，这可能会触发“临时疯狂”）。
