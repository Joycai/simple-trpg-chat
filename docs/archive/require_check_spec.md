# hoster发起检定的功能需求

hoster可以主动要求房间内的成员进行检定（包括bot）。操作方式是点击顶部工具栏的“发起检定”按钮，然后选择需要检定的人员，再选择需要检定的`技能`。然后点击“发起”。

- 检定的范围为当前房间-》当前频道内的成员。也就是在公共频道内，可以选择全部的人员，私聊情况下，默认直接对私聊对象发起。
- 可以选择“要求全员（不含bot）”来选择除bot和自己外的所有人进行
- 可以单独选中房间内的成员，然后点击发起检定，来对需要检定的玩家发起检定。这个成员列表中，需要区分bot和player
- 检定信息会在当前频道发出，且频道成员均可见。
  - host会看到这样的信息：自己发起某个技能要求检定
  - 其他成员（被指定的）会看到：hoster要求你进行`技能`检定，并附带一个投掷的视觉图标；点击该图标可以直接进行检定；如果该成员没有设置这个技能，会弹出框要求其先设定该技能数值，数值会被直接保存到该成员的技能里。然后再自动完成检定。
    - 指定者完成本次检定请求后，不能再次投掷（投掷图标失效/不可再点击）。
  - 其他成员（未被指定的）会看到：host 要求【目标列表】来进行技能检定，但是不会有投掷图标
- 当目标投掷后，host自己会看到消息，x/y人已经完成检定。
- 如果要求bot检定，bot也可以响应【如果勾选了tool】

投掷规则参考 [指令](command_spec.md) 中有关`ra/rc`指令的描述。设置技能的逻辑参考`.st`部分。
