# 这是一个狩猎魂者的规则摘要

## 人物基础属性

基础属性仅3项，每项属性**最低为1，最高为9**。基础属性都可以通过查表获取到对应的**强度值**（如**体魄**对应**体魄强度**）。

衍射属性有些基于**属性值**（如**体魄值**），有些基于属性对应的**强度值**（如**体魄强度**）

**基础属性**

- **体魄**
- **智慧**
- **心魂**

基础属性有对应的等级表示：

| 等级   | 对应属性 |
|:-----|:----:|
| E    |  1   |
| D    |  2   |
| C    |  3   |
| B    |  4   |
| A    |  5   |
| S    |  6   |
| SS   |  7   |
| SSS  |  8   |
| SSS+ |  9   |

**强度值**

- **体魄** 对应 **体魄强度**
- **智慧** 对应 **术法强度**
- **心魂** 对应 **灵能力强度**

换算关系：**属性值** /2 后向下取整极为对应**强度值**

如：

- 9点**体魄**，对应**体魄强度**为 9/2=4.5，下取整后为4
- 4点**体魄**，对应**体魄强度**为 4/2=2，下取整后为2
- 5点**体魄**，对应**体魄强度**为 5/2=2.5，下取整后为2
- 1点**体魄**，对应**体魄强度**为 1/2=0.5，下取整后为0
- 6点**智慧**，对应**术法强度**为 6/2=3，下取整后为3
- 7点**心魂**，对应**灵能力强度**为 7/2=3.5，下取整后为3

### 衍生属性

**生命值**

计算方式：5+**体魄强度**

**灵力值**

计算方式：5+**智慧**x2+**心魂**

## 灵识

**灵识**为三项基础属性之和，初始为9点，也就是等同于，可以用9点自由分配给基础属性（注意，每个基础属性至少为1）。
**灵识**总数取决于角色等级/主持人要求。


## 检定规则

检定基本规则为：

投掷 1D20+xD4+yD6 >=DC 即为成功

### DC
由主持人给出，一般为10，也可能更高

### 成功等级

投掷结果**大于等于**DC则表示检定成功，此时成功等级为**1**。出目每溢出5点(向下取整)，则成功等级+1.
举例：
- 投掷结果26，DC为10，则成功等级为 1+(26-10)/5=1+3.2=1+3（3.2向下取整）=4
- 投掷结果21，DC为20，则成功等级为 1+(21-20)/5=1+0.2=1+0（0.2向下取整）=1
- 投掷结果9，DC为10，则检定失败

### xD4 (加骰)

x数值来源于角色自身技能/属性等等

### yD6 (时髦骰)

x数值来源于主持人奖励取值范围为-3～+3，由主持人给出。
