# Simple TRPG Chat — 管理员指南

**Version**: 0.11.3 | **Last Updated**: 2026-07-25

---

## 管理员角色

管理员（Admin）拥有系统的最高权限，可以管理所有用户账号。Admin 后台访问路径：`/admin`。

> ⚠️ 初始管理员账号为 `admin / admin123`，首次部署后建议立即创建其他管理员账号。

---

## Admin 后台功能

访问 `/admin` 进入后台管理页面（需以 admin 角色登录）。

### 1. 创建账号

**支持的账号角色：**

| 角色 | 英文标识 | 权限 |
|------|---------|------|
| 管理员 | admin | 全部权限，可管理所有账号 |
| 主持人 | host | 可以创建和管理房间，暗骰 |
| 玩家 | player | 可加入房间聊天和骰点 |

**创建步骤：**
1. 在后台"Create New Account"表单中填写：
   - **Username** — 登录用户名（唯一，不可重复）
   - **Password** — 登录密码
   - **Display Name** — 显示名称（默认可在列表中展示的名称）
   - **Role** — 账号角色（admin / host / player）
2. 点击"Create User"提交

### 2. 查看账号列表

后台下方"Account List"表格展示所有已注册用户：

| 列 | 说明 |
|----|------|
| Username | 登录用户名 |
| Display Name | 显示名称 |
| Role | 角色（颜色标记：红色=admin / 绿色=host / 蓝色=player） |
| Actions | 操作按钮 |

### 3. 删除账号

- 点击账号行的 "Delete" 按钮删除该账号
- 初始管理员账号 `admin` 的 Delete 按钮默认禁用，无法删除
- 删除账号后，其关联的房间和消息数据会自动级联删除

## 其他后台模块

除账号管理外，`/admin` 侧边栏还提供以下模块（详见 [`docs/arch/admin-panel.md`](../arch/admin-panel.md)）：

| 模块 | 路径 | 说明 |
|------|------|------|
| 仪表盘 | `/admin` | 实时在线人数、访问流量、服务器负载、图片缓存概览 |
| AI 设置 | `/admin/ai` | 开关 AI 功能、管理 Bot 预设模板、配置共享 AI 提供商 |
| 站点配置 | `/admin/config` | 站点标题、默认主题、敏感词黑名单、公安备案信息、Favicon |
| 图片缓存 | `/admin/images` | 图片缓存看板与按房间清理 |
| 房间管理 | `/admin/rooms` | 查看/管理全站所有房间 |
| Token 用量 | `/admin/usage` | AI Token 用量分析（按用户 / 提供商 / 日期筛选） |
| 用户管理 | `/admin/users` | 角色、封禁、改密、AI 点数、登录历史 |

## 最佳实践

### 账号管理建议
1. **创建主持人专用账号** — 用 admin 创建 host 角色账号，分发给 DM/主持人使用
2. **玩家使用独立账号** — 为每位玩家创建 player 角色账号，而非共享账号
3. **定期备份数据库** — 项目已迁移至 PostgreSQL。请使用 `pg_dump` 对数据库进行定期备份，以防数据丢失。

### 安全注意事项
1. 部署到公网时确保 `AUTH_SECRET` 环境变量是一个强随机字符串
2. 初始管理员密码 `admin123` 仅用于首次设置，应尽快创建自己的管理员账号并限制初始管理员的使用
3. 不要在公开渠道直接分享房间密钥
