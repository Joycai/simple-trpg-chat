# Simple TRPG Chat — 用户手册

**Version**: 0.23.1 | **Last Updated**: 2026-08-16

---

## 概述

Simple TRPG Chat 是一个轻量化的网页版跑团工具，支持多房间、角色管理、实时聊天和骰点功能。支持三种角色：**管理员(Admin)**、**主持人(Host)** 和 **玩家(Player)**。

---

## 快速开始

### 登录

1. 打开浏览器访问部署后的地址（如 `http://localhost:3000`）
2. 在登录页面输入管理员分配的用户名和密码
3. 登录后自动进入**大厅页面**

**初始管理员账号**（首次部署时可用）：

| 用户名 | 密码 |
|--------|------|
| admin  | admin123 |

> ⚠️ 首次登录后请尽快修改密码或创建自己的账号。

## 玩家指南

### 1. 浏览和加入房间

登录后，你会在**大厅页面**看到所有活跃的房间列表。

- 点击 **"🔑 输入密钥加入"** 按钮
- 输入主持人提供的**房间密钥**，点击"加入"
- 加入成功后，房间卡片会显示蓝色"已加入"标签
- 点击 **"进入房间 →"** 进入聊天界面

### 2. 修改昵称

进入房间后，在顶部栏右侧点击 **"✏️ 当前昵称"**：

- 点击昵称文字进入编辑模式
- 输入新昵称（最长 20 个字符）
- 按 `Enter` 保存，按 `Esc` 取消
- 保存后，后续发送的消息将使用新昵称

> 📝 昵称是**房间级别**的，在不同房间可以使用不同昵称。
> 已发送的历史消息不会随昵称修改而改变。

### 3. 发送消息

在房间底部输入框输入文字，点击"发送"或按 `Enter` 发送文本消息。

- 消息气泡以不同颜色区分：蓝色为自己发送，灰色为他人发送
- 每条消息显示发送者昵称和时间
- 每条消息显示发送者头像（昵称首字母）

### 4. 骰点

点击输入框左侧的 **🎲** 按钮打开骰点面板：

1. 选择骰子面数：d4 / d6 / d8 / d10 / d12 / d20 / d100
2. 调整数量（默认 1，最大 20）
3. 点击 **"🎲 N面骰"** 按钮投出
4. 骰点结果会以黄色消息气泡展示，显示每个骰子的目数和总和
5. 骰点面板会保留上一次结果供参考

## 主持人指南

主持人拥有玩家全部功能，额外还有以下权限：

### 1. 创建房间

- 在大厅页面点击右上角 **"＋ 创建房间"** 按钮
- 输入房间名称，点击"创建"
- 系统自动生成**随机密钥**，创建者无需手动输入密钥即可进入
- 创建成功后，将**房间 ID 和密钥**分享给玩家即可

> 🔑 密钥在创建时自动生成（8 位十六进制字符串），可在房间页面查看。

### 2. 暗骰（非公开骰点）

在骰点面板中勾选 **"🔒 暗骰"** 选项：

- 暗骰结果仅**主持人本人**和**发送者**可见
- 普通玩家看不到暗骰消息
- 暗骰消息以紫色气泡 + 🔒 标记显示

### 3. 管理房间

- 作为房间创建者，房间会始终标记为"主持人"
- 进入房间无需输入密钥
- 可以复制房间链接分享给其他人

## 指令系统

在聊天输入框中发送以 `.` 开头的消息可以触发特殊指令，用于投点、技能管理等操作。

### 设置技能 — `.st`

使用 `.st` 指令可以设置自己的技能值（必携 0-100）：

**格式：**
```
.st 技能名 数值
```

**示例：**
```
.st 侦查 50                     # 设置"侦查"为 50
.st 侦查 50 聆听 60 图书馆 30   # 批量设置三个技能
.st 侦查50聆听60图书馆30        # 紧凑格式（可不加空格）
```

- 技能值范围：0-100
- 重复设置同一技能会自动覆盖
- 设置成功后会收到系统反馈消息

### 技能检定 — `.rc`

使用 `.rc` 指令对已设置的技能进行 d100 检定：

```
.rc 侦查    # 对"侦查"技能进行检定
```

- 系统自动投 d100，结果 ≤ 技能值则成功 ✅，否则失败 ❌
- 如果房间投点规则设为 **COC 7th** 模式，还会显示：
  - 🟢 **大成功**（01-05）
  - 🔴 **大失败**（96-100）

### 直接投骰 — `.rd`

```
.rd100      # 投 1 个 d100
.rd20       # 投 1 个 d20
.rd10       # 投 1 个 d10
```

### 查看帮助 — `.help`

发送 `.help` 查看所有可用指令列表。

## 技能面板

房间页面 Header 右侧的 **📋** 按钮可以打开技能面板：

- **查看技能**：显示当前的所有技能及进度条（红/黄/蓝三级色）
- **添加技能**：通过表单输入技能名称和数值
- **编辑技能**：点击数值进入编辑模式（Enter 保存 / Esc 取消）
- **删除技能**：悬停技能行显示 🗑 删除按钮
- 技能面板与 `.st` 指令双向同步

---

## 房间设置

主持人点击房间 Header 的 **⚙️** 齿轮按钮打开房间设置：

- **房间主题**：切换房间的整体视觉风格（默认 / 古旧羊皮卷🏺 / 克苏鲁🦑 / 远古神社⛩️ / 霓虹雨夜🌧️ / 苍穹幻境🔮）
- **规则模板**：决定检定指令（`.rc` / `.sc` / `.st`）的判定方式
  - **Basic（基础骰点）** — 纯数值骰点，无特殊判定
  - **COC 7th** — d100 检定，启用大成功(01-05)🟢 / 大失败(96-100)🔴 及理智检定 `.sc`
  - **D&D 5e** — d20 检定体系

## 常见问题

### 我忘记了密码？
联系管理员重置密码。

### 一个玩家可以加入多个房间吗？
可以。玩家可以同时加入多个活跃房间，在不同房间中使用不同昵称。

### 消息历史能保存多久？
消息持久化存储在服务器数据库中，历史记录永久保存。进入房间时会自动加载全部历史消息。

### 暗骰消息其他人能看到吗？
不能。暗骰消息仅对**主持人**和**发送者**可见，普通玩家看不到暗骰内容。

### 主持人能看到我的暗骰吗？
暗骰是主持人专用的功能。普通玩家没有暗骰选项。
